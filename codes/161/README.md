# CodeForge – Gallery 161

Reproduction of the public CodeForge MagicUI landing page from reference screenshots and its public website. Standalone HTML, CSS and vanilla JavaScript.

## Open

Open `index.html` in a browser or start VS Code Live Server. All image files are in `assets/` and do not require an online service. No npm or build process is needed.

## Files

- `index.html` – markup for every section of the long landing page.
- `styles.css` – responsive baseline layout.
- `effects.css` – partner logos, transitions, scroll animations, illustration effects, light/dark styling.
- `main.js` – navigation, theme, pricing, FAQ, review demo, integration search and testimonials.
- `effects.js` – gallery slideshow, visual reveals, terminal sequence and ticker optimization.
- `assets/` – locally stored photographs, partner wordmarks, illustrations.

## Interaction

- Navigation links and the Products dropdown.
- Light/dark theme and mobile navigation.
- Four gallery tabs with changing imagery and auto-progress. Manual selection pauses auto-rotation for 18 seconds.
- Animated terminal, agent-flow connectors and globe/map pulses while scrolling.
- Code suggestion apply/reset button.
- Interactive example agent controls and integrations filtering.
- Anonymous quote marquee with pausing on hover (no names or portrait images).
- Monthly/annual billing switch, FAQ disclosure, interactive prompt.
- Reduced-motion support.

## Notes

This is a design study. Actual AI features, GitHub authentication, payments and external integrations are **not** connected. Some transitions and visuals are approximations because source design files and proprietary app code were not provided. Brand logos and other image crops are sourced from the user-provided reference images.
